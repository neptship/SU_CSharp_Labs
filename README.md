# SU_CSharp_Labs

Решения лабораторных работ по курсу **"Основы программирования"** для студентов Самарского университета.

## 📁 Содержание

- [Лабораторная работа 1: Линейные программы и программы с ветвлениями](Lab01)
- [Лабораторная работа 2: Программы с использованием циклов](Lab02)
- [Лабораторная работа 3: Программы с использованием циклов-2](Lab03)
- [Лабораторная работа 4: Простейшие классы](Lab04)

## 🧪 Как использовать

1. Клонируйте репозиторий:

```bash
git clone https://github.com/neptship/SU_CSharp_Labs.git
cd SU_CSharp_Labs
```

2. Перейдите в папку с лабораторной работой:
```bash
cd Lab01
```

3. Откройте решение в Visual Studio или Rider.

## ⚠️ Важно: академическая честность

Материалы даны для ориентира. Пожалуйста:
- Не копируйте «1 в 1». Переписывайте своими словами и пониманием.
- Меняйте структуру решения, имена, стили — но сохраняйте корректность.
- Понимайте каждую строку: вы должны уметь объяснить свой код.

Используйте репозиторий как подсказку и источник идей, а не как готовое решение.
